Vehicle Management Web Application

This page is a static file served using the Node.js fs module.

Part A: HTTP Server (port 3000)

  • GET / welcome page
  • GET /vehicles all vehicles (JSON)
  • GET /about application info
  • GET /info this page
  • POST /add-vehicle add a vehicle

Part B: Express REST API (port 4000)

  • GET /vehicles, GET /vehicles/:id
  • POST /vehicles
  • PUT /vehicles/:id
  • DELETE /vehicles/:id

Built with Node.js, HTTP module, FS module and Express.js. No database is used.
